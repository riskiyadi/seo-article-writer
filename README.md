# SEO Article & Blog Writer AI

Web app berbasis HTML, CSS, dan JavaScript untuk menyusun kerangka maupun draf artikel SEO lengkap secara otomatis dengan integrasi Gemini AI. Dilengkapi juga dengan pengecek kepadatan kata kunci secara langsung dan kalkulator estimasi biaya jasa penulisan konten.

## Fitur Utama

- **Generator Artikel Otomatis:** Menghasilkan rekomendasi judul H1, meta description, serta draf artikel lengkap menggunakan Gemini API.
- **Generator Kerangka Cepat:** Menyusun struktur outline H1, H2, dan H3 secara instan tanpa memerlukan API Key.
- **Live SEO & Keyword Checker:** Menghitung jumlah kata, frekuensi kemunculan kata kunci, dan persentase keyword density secara real-time.
- **Kalkulator Harga & Order WhatsApp:** Menghitung estimasi tarif penulisan berdasarkan jenis konten dan jumlah kata, lalu mengarahkan pesanan langsung ke WhatsApp.
- **Penyimpanan Lokal:** API Key disimpan di `localStorage` browser perangkat pengguna.

## Cara Menggunakan

1. Buka halaman web app melalui browser.
2. Masukkan **Gemini API Key** dari Google AI Studio pada bagian pengaturan atas lalu tekan **Simpan** jika ingin memakai fitur penulisan otomatis.
3. Isi **Topik Artikel**, **Kata Kunci Utama**, **Jenis Konten**, dan **Target Jumlah Kata**.
4. Tekan tombol **Tulis Artikel Otomatis dengan AI** atau **Buat Kerangka Cepat**.
5. Pantau skor kepadatan kata kunci di kolom editor, atau tekan **Contact Me Now!** untuk memesan jasa penulisan.
